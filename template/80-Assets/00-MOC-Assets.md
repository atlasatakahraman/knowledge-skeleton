# Assets MOC

Binary attachments for vault notes: pasted screenshots, diagrams, exported images. Obsidian's
`attachmentFolderPath` points at `Images/`, so a paste lands there instead of beside the note.

| Path | Contents |
|---|---|
| `Images/` | Screenshots, pasted images, exported PNG/JPG |
| `Diagrams/` | Source diagrams: `.excalidraw`, `.svg`, `.drawio` |
| `Repos/<Remote-Name>/` | Per-repo brand masters: logos, banners, icon sources. The export ships in the repo |
